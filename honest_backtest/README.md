## 2. 诚实版回测 (`polymarket_kelly_backtest.py`)

把帖子图里那 4 个公式（EV / Kelly / Bayes / Maker-Taker）全部实现，做蒙特卡洛：

| 场景 | 假设 | 1200 起，1000 笔，500 次 MC 的中位数终值 | 达到帖子 664× 概率 |
|---|---|---|---|
| 1. 现实派 | 你的估值误差 σ=4%（略好于市场） | **$2,053**（+71%）| **0 %** |
| 2. 顶级玩家 | σ=2%（显著 edge） | **$3,035**（+153%）| **0 %** |
| 3. 玄学派 | σ=10%（你和市场一样瞎） | **$107**（-91%）| **0.2 %** |
| 4. 高频强度 | 34000 笔 + σ=3% | 模型爆炸（见下） | 100%（**不真实**）|

**场景 4 为什么"成立"？** 这是回测里最常见的陷阱：当你假设"每笔都有 edge"且让它复利 34000 次时，Kelly 会把你带到数学上的天文数字。这正是 Twitter 帖子制造的幻觉。现实里你无法对**每一笔**都拥有恒定 edge——市场价本身就是所有参与者估计的共识，你的信息没有比市场更好的先验保证。

## 3. 使用

```bash
pip install numpy
python polymarket_kelly_backtest.py --sigma 0.04 --kelly_frac 0.5 --n_bets 1000 --n_runs 500
```

参数：
- `--sigma`：你估值的噪声（越小表示你越准。研究级预测市场一般 σ≈0.05–0.10）
- `--kelly_frac`：Kelly 比例，推荐 0.25–0.5
- `--n_bets`：总下注数
- `--n_runs`：蒙特卡洛次数

## 结论

帖子的 **$797K / 49 天 / 664×** 三个数字**机械上是真的**（API 能查到），但意义完全不是它想让你理解的那个：

1. 那 79.7 万 profit 是**会计口径下的平仓盈亏累加**，不是净值变化
2. 账户当前只有 $4.41，最近 118 个仓位 117 个归零
3. 77.9M 交易量 / 79.7 万 profit ≈ 1% 返佣率，**更像刷返佣 / 做空投 / 刷榜**的特征
4. 图里那套"量化框架"本身数学无误，但被套上了**每笔都能稳定找到 edge** 的不现实假设
5. "Opus 4.7"、"Hermes CLI"、"7200 万笔 Backer 数据集"——都是带感词，没对应真实产品
6. 地址链接末尾的 `?via=following` 是 referral 参数，帖主大概率**靠拉人返佣赚钱**

照这个帖子搭一套 VPS+Bot 去跑，你不会变成 79.7 万，你大概率变成 $4.41。
